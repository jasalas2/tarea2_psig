# Patrones de registro de Agalychnis callidryas en Costa Rica (iNaturalist)

**Autor:** _[Jarod Salas Díaz]_

**Cuaderno:** [cuaderno.ipynb](./cuaderno.ipynb)

Análisis con pandas y matplotlib de observaciones de la rana de ojos rojos
(*Agalychnis callidryas*) en Costa Rica, a partir de datos descargados de
iNaturalist. Explora la tendencia anual de observaciones, el patrón
estacional por mes y la distribución geográfica por provincia.
